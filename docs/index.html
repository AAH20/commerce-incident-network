Open-source diagnostic · synthetic demonstration

Find Shopify and Google Merchant Center product mismatches

Commerce Incident Network compares complete, customer-authorized snapshots for one channel scope. It finds missing offers, disapprovals, price differences, and availability differences, then produces an operator queue and a report you can recompute.

What does it diagnose?

QuestionObserved signalNext human check
Is an offer disapproved?Google processed-product approval status in the declared country and reporting context.Read the issue details in Merchant Center; this tool does not infer the policy reason.
Do prices disagree?Exact USD storefront and channel prices for an explicitly mapped SKU and offer.Check promotion and pricing intent before changing either value.
Does availability disagree?Shopify quantity compared with the channel's in-stock or out-of-stock state.Check inventory policy and feed timing.
Did an issue disappear?The condition is absent in a newer, complete snapshot of the same scope.Confirm the platform state and record the actual correction separately.

Run and verify it locally

Python 3.11 or newer is required. From a clone of the repository, these commands use only fictional fixtures and write to /tmp.

PYTHONPATH=src python3 -m commerce_incident_network run fixtures/demo/day1 /tmp/cin-day1 --as-of 2026-09-24T12:00:00Z
PYTHONPATH=src python3 -m commerce_incident_network run fixtures/demo/day2 /tmp/cin-day2 --as-of 2026-09-25T12:00:00Z --previous /tmp/cin-day1/report.json
PYTHONPATH=src python3 -m commerce_incident_network verify fixtures/demo/day1 examples/reports/day1.json
PYTHONPATH=src python3 -m commerce_incident_network verify fixtures/demo/day2 examples/reports/day2.json --previous examples/reports/day1.json

Open /tmp/cin-day2/dashboard.html to inspect the offline report. The verifier recomputes from supplied files; source hashes detect file drift but cannot authenticate the platform that produced a real export.

What has been demonstrated?

Implemented: deterministic comparison, JSON/CSV/HTML reports, offline verification, a local SQLite operator desk, and read-only connector code. Tested here: fictional fixtures and mocked Shopify and Google API responses. Not demonstrated: a live merchant-authorized capture, automated correction, root-cause diagnosis, or incremental sales.

The optional daily margin figure is a historical-velocity priority proxy, not estimated lost or recovered revenue. See the input contract and pilot architecture before using customer-authorized data.
